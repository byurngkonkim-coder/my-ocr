## 3. 이 세션에서 한 일 (시간 순)

### 3-1. 교정기 — 정제본 23권으로 오작동 측정·수정 (커밋 MyOCR `e288a85` · 01_OCR `801098b` · MD `5e59aae`, push 완료)
`01_OCR.../02_결과/백업/` 23권(13MB, 40,039줄)은 LLM 정제가 끝난 바른 문장이라, 교정기가 바꾸는 곳은 오작동이다.

| 측정 | 이전 | 이후 |
|---|---:|---:|
| 정제본에서 바꾼 곳 | 23,295 (줄의 32.6%) | 87 (0.2%) |
| 실제 OCR 원문(1분의사결정 165쪽)에서 바꾼 곳 | 135 (거의 전부 훼손) | 8 (6곳 정상 교정) |

주요 원인: 괄호 앞 띄움(13,182곳) · '한다/하되/가/서/도' 를 조각으로 보고 붙임(6,377) · 긴 단어 쪼개기(3,867) · '위해서는'→'위해 서는'(1,700여).
세부는 커밋 메시지 참조. 보존 문장 20건을 세 저장소 테스트에 추가.

## 4. 결과_MD 98권 보정 — 남은 작업

**진단(이전 버전 파이프라인이 남긴 훼손, `scan_md.py`·`scan_md2.py`):** 괄호 앞 띄움 21,120 · '있어야한다' 붙임 10,067 · '위해 서는' 4,747 · '것 이다' 4,321 · 외래어 쪼갬 1,006 · 웹주소 띄움 978 · 숫자→따옴표 **644(복구 불가)** 등.

**미리보기 결과(`repair_md.py`, 원본 불변):** 48,337곳 되돌림. 숫자 훼손 644곳은 파일·줄 목록으로 리포트(`보정리포트.md`).

**⚠ 실행 전 반드시 확인할 위험** ⟦E3: 수치 차이로 추정⟧
- `것 이다 쪼갬` 규칙이 9,072곳으로 진단치(4,321)의 2배 — 패턴 `것 (은|을|에|도|과|으로…)` 에 **뒤 경계가 없어** `것 은행`→`것은행`, `것 에너지`→`것에너지` 처럼 잘못 붙일 수 있음. 뒤 경계 `(?![가-힣])` 또는 조사 뒤 공백·구두점 조건을 넣고 다시 셀 것
- `괄호 앞 띄움` 21,960곳 — 저자가 원래 띄어 쓴 괄호도 붙이게 됨(한국어 표기 원칙상은 붙임이 맞음)
- `보조용언 한다 붙임` 8,760곳 — `([가-힣](야|을|를|게|록))한다` 가 단어 속을 건드리는지 표본 확인

**검증 절차:**
1. `repair_md.py` 의 `것 이다` 규칙에 뒤 경계 추가
2. 미리보기 폴더(세션 scratchpad)에 다시 실행 → `sample_diff.py` 로 유형별 표본 30개씩 눈으로 확인
3. 오변환 0 확인 후 `Raw/파일형식변환기/결과_MD_보정/` 에 실행 (원본 `결과_MD` 는 건드리지 않음)
4. `보정리포트.md` 의 숫자 훼손 644곳은 원본 PDF 대조 또는 수정된 변환기로 재변환 필요 — 사용자에게 보고
