## 3. 엔드유저 2계층 구조 (Folder Architecture)

각 프로그램은 비개발자 사용자의 인지 부하를 없애고 안전성을 보장하기 위해 통일된 2계층 구조를 따릅니다:

```
[User Layer - 최상위 루트 (사용자 조작 영역)]
├── 실행 런처 (.bat)      : 더블클릭으로 즉시 실행 (START_OCR.bat / run.bat / run_gui.bat)
├── 바로가기 (.url)       : 웹 대시보드 브라우저 바로가기
└── 입력/결과 폴더         : 원본 투입 및 최종 결과물 저장소 (01_입력, 02_결과, 결과/)

[Internal Layer - 서브 디렉터리 (시스템 및 문서 영역)]
├── engine/               : 실행 엔진, 가상환경(venv), 단위 테스트, 백엔드 코드
├── docs/                 : 사용자 매뉴얼, 설계 가이드, 정제 규칙서, 인수인계서
└── _백업/                : 이동 로그(move_log.tsv) 및 원본 보존 아카이브
```
