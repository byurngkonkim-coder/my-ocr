# 표 OCR - 캡처 표 문자추출

캡처된 **표(테이블) 이미지·PDF에서 문자를 정확히 추출**하여 **표 형식(엑셀/CSV/TSV)** 으로
내보내는 독립 실행형 프로그램입니다. 한글 인식 정확도가 높은 **PaddleOCR**의
표 구조 인식 파이프라인을 사용하며, 인터넷에 데이터를 보내지 않고 **내 PC 안에서만**
처리합니다. (최초 1회 모델 다운로드 시에만 인터넷이 필요합니다.)

## 주요 기능

- 📊 **표 추출**: 표의 행·열·셀 구조를 인식해 격자로 복원
  - 💾 **엑셀(.xlsx) 저장** — 표 여러 개면 시트별로 저장
  - 💾 **CSV 저장** — 현재 표
  - 📋 **표 복사(TSV)** — 엑셀/구글시트에 바로 붙여넣기
- 📁 **폴더 일괄 처리**: 폴더 안 여러 이미지를 한 번에 인식해 **하나의 CSV/엑셀로 통합**
  (여러 캡처에서 데이터를 긁어모으는 크롤링 같은 효과)
- 📝 **일반 텍스트 모드**: 표가 아닌 이미지/문서의 줄글 추출
- 🖼 이미지(PNG/JPG/BMP/TIFF/WEBP) · 📄 PDF(모든 페이지) 지원
- 🌐 언어: 한국어(한글+영문) · 영어 · 중국어 · 일본어
- 🔎 저해상도 표 이미지는 자동 확대해 인식 정확도 보정

## 설치 방법

1. **Python 3.8 ~ 3.12** 설치 (확인: 명령 프롬프트에서 `python --version`)
   - 없으면 <https://www.python.org/downloads/> 에서 설치 (**"Add Python to PATH"** 체크)
2. 이 폴더의 **`install.bat`** 더블클릭 → 가상환경 생성 + 패키지 자동 설치
   - 표 인식 관련 패키지 포함, 용량이 커서 몇 분 걸립니다. (인터넷 필요)
3. 설치가 끝나면 **`run.bat`** 더블클릭 → 프로그램 실행

## 사용 방법 (한 장씩)

1. `run.bat` 실행 → 프로그램 창이 열립니다.
2. **[🖼 이미지 열기]** 또는 **[📄 PDF 열기]** 로 표 이미지를 불러옵니다.
3. **모드**를 **표 추출**(기본), **언어**를 **한국어**로 둡니다.
4. **[▶ 인식 실행]** 클릭. (최초 1회는 모델 로딩으로 시간이 걸립니다)
5. 오른쪽에 표가 **격자**로 표시됩니다. (표가 여러 개면 탭으로 구분)
6. **[💾 Excel]** / **[💾 CSV]** 저장, 또는 **[📋 복사]** 후 엑셀에 붙여넣기.

## 폴더 일괄 처리 (여러 이미지 → 하나의 표)

여러 장의 표 이미지를 한 폴더에 모아, 한 번에 **하나의 통합 데이터셋**으로 만듭니다.

**GUI에서:**
1. **[📁 폴더 일괄]** 클릭 → 이미지가 든 폴더 선택
2. 확인하면 각 이미지를 순서대로 표 인식 (진행 상황이 상태바에 표시)
3. 완료되면 **[통합]** 탭에 모든 표가 `출처파일` 열과 함께 합쳐져 표시됩니다.
4. **[💾 Excel]**(통합 + 이미지별 시트) 또는 **[💾 CSV]**(통합)로 저장.

**드래그앤드롭 / 명령줄 (자동화):**
- `batch_run.bat` **위에 이미지 폴더를 끌어다 놓으면** 자동 실행
  → 폴더 안에 `폴더명_통합.csv` / `폴더명_통합.xlsx` 생성
- 또는 명령줄:
  ```
  venv\Scripts\python.exe batch_folder.py "C:\경로\이미지폴더" --lang korean
  ```
  옵션: `--recursive`(하위 폴더까지), `--out 접두어`, `--no-dedup-header`(반복 헤더 유지)

> **통합 규칙**: 각 행 앞에 `출처파일` 열이 붙고, 첫 이미지의 헤더를 대표로 삼아
> 이후 이미지의 동일한 헤더 행은 자동으로 생략합니다.
> (같은 양식의 표 여러 장을 이어붙일 때 최적입니다.)

> **팁 (정확도 높이기)**: 표 선이 뚜렷하고 해상도가 높을수록 정확합니다.
> 저해상도는 자동 확대되지만, 원본이 선명할수록 좋습니다.

## 폴더 구성 (엔드유저 2계층 구조)

```
MyOCR/
├── run.bat                 # GUI 프로그램 실행 (더블클릭)
├── batch_run.bat           # 폴더 일괄 추출 실행 (폴더 드래그앤드롭 / 더블클릭)
├── 결과/                   # 산출물 기본 저장 폴더 (CSV, Excel)
│
├── engine/                 # 내부 엔진 및 가상환경 격리
│   ├── ocr_app.py          # GUI 애플리케이션
│   ├── ocr_engine.py       # 텍스트 OCR 엔진 (RapidOCR 우선/PaddleOCR 폴백)
│   ├── table_engine.py     # 표 구조 인식 엔진 (RapidTable/SLANet-Plus)
│   ├── uth_fixed_engine.py # 고정 레이아웃 전용 엔진
│   ├── korean_corrector.py # 한글 맞춤법/띄어쓰기 정제 모듈
│   ├── batch_folder.py     # 폴더 일괄 처리 CLI
│   ├── batch.py            # 일괄 처리 모듈 (헤더 병합)
│   ├── exporters.py        # 엑셀/CSV/TSV 저장 모듈
│   ├── install.bat         # 가상환경 구축 스크립트
│   ├── requirements.txt    # 패키지 의존성 명세
│   ├── tests/              # 회귀 테스트 스크립트
│   └── venv/               # 독립 가상환경
│
├── docs/                   # 사용자 가이드 및 지침 문서
│   ├── README.md
│   └── README.zip
│
├── samples/                # 테스트용 샘플 이미지
│   ├── test_batch/
│   └── test_table.png
│
└── _백업/                  # 이동 기록(move_log) 및 원본 보존
```

## 문제 해결

- **`install.bat` 이 "venv creation failed"** → Python이 없거나 PATH에 없음.
  python.org 정식 버전 설치(Microsoft Store 버전보다 권장) 후 재시도.
- **표를 못 찾음 / 셀이 어긋남** → 표 선이 흐리거나 기울어진 스캔은 정확도가 떨어집니다.
  반듯하고 선명한 캡처를 쓰거나 표 부분만 잘라서 넣어 보세요.
- **첫 인식이 오래 걸림** → 정상입니다. 최초 1회 표 인식 모델을 로딩/다운로드하는 중입니다.
- **한글이 이상하게 인식됨** → 언어가 "한국어"인지 확인하세요.

## 참고

- 엔진: [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) (Apache-2.0, 오픈소스)
- 표 구조 인식: `TableRecognitionPipelineV2` + 한글 인식 모델 `korean_PP-OCRv5_mobile_rec`
- 표 파이프라인은 `enable_mkldnn=False`로 실행합니다 (paddlepaddle 3.x oneDNN 버그 회피).
- GPU가 있으면 GPU용 paddlepaddle 설치로 속도를 크게 높일 수 있습니다.
