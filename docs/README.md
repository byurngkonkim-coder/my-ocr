# 표 OCR - 캡처 표 문자추출

캡처된 **표(테이블) 이미지·PDF에서 문자를 정확히 추출**하여 **표 형식(엑셀/CSV/TSV)** 으로
내보내는 독립 실행형 프로그램입니다. **RapidOCR·RapidTable**(ONNX Runtime, PP-OCRv5 한국어 모델)로
표 구조와 글자를 인식하며, 인터넷에 데이터를 보내지 않고 **내 PC 안에서만**
처리합니다. (최초 1회 모델 다운로드 시에만 인터넷이 필요합니다.)

## 주요 기능

- 📊 **표 추출**: 표의 행·열·셀 구조를 인식해 격자로 복원
  - 💾 **엑셀(.xlsx) 저장** — 표 여러 개면 시트별로 저장
  - 💾 **CSV 저장** — 현재 표
  - 📋 **표 복사(TSV)** — 엑셀/구글시트에 바로 붙여넣기
- 📁 **폴더 일괄 처리**: 폴더 안 여러 이미지를 한 번에 인식해 **하나의 CSV/엑셀로 통합**
  (여러 캡처에서 데이터를 긁어모으는 크롤링 같은 효과)
- 📝 **일반 텍스트 모드**: 표가 아닌 이미지/문서의 줄글 추출
  - **문장 정제**(기본 켬): 쪽번호·반복 머리글 제거, 끊긴 줄·문장 잇기, 전각 문자 정리, 한글 띄어쓰기 보정
  - **부속물 삭제**(기본 끔): 책의 판권·도서 광고 등 제거
  - 📚 **책 구조 정비**(PDF + 문장 정제): ① 줄 위치로 여백의 쪽번호·머리말·꼬리말 제거 →
    ② 앞부분 **차례**의 장·절 제목을 본문에서 찾아 MD 제목(`#`·`##`…)으로, 제목 앞뒤 빈 줄 →
    ③ 문장 정제. 결과는 **MD + TXT** 두 형식 (아래 참조)
- 🗂 **사용자관리(고정양식) 모드**: UtradeHub '사용자관리' 화면 캡처(1788×892) 전용 추출
- 💾 **결과 자동 저장**: 인식이 끝나면 `결과\` 폴더에 바로 저장 (아래 참조)
- 🖱 **끌어다 놓기**: 왼쪽 미리보기 영역에 이미지·PDF·폴더를 끌어다 놓아 열기
- 🖼 이미지(PNG/JPG/BMP/TIFF/WEBP) · 📄 PDF(모든 페이지) 지원
- 🌐 언어: 한국어(한글+영문) · 영어 · 중국어 · 일본어
- 🔎 저해상도 표 이미지는 자동 확대해 인식 정확도 보정

## 설치 방법

1. **Python 3.10 ~ 3.12** 설치 (확인: 명령 프롬프트에서 `python --version`, 검증 환경 3.12)
   - 없으면 <https://www.python.org/downloads/> 에서 설치 (**"Add Python to PATH"** 체크)
2. **`engine\install.bat`** 더블클릭 → `engine\venv` 가상환경 생성 + 패키지 자동 설치
   - 몇 분 걸립니다. (인터넷 필요)
   - 프로그램을 업데이트(`git pull`)한 뒤에도 한 번 다시 실행하세요. 새 패키지가 추가될 수 있습니다.
3. 설치가 끝나면 최상위 폴더의 **`run.bat`** 더블클릭 → 프로그램 실행

## 사용 방법 (한 장씩)

1. `run.bat` 실행 → 프로그램 창이 열립니다.
2. **[🖼 이미지 열기]** 또는 **[📄 PDF 열기]** 로 파일을 불러옵니다.
   (왼쪽 미리보기 영역에 파일을 **끌어다 놓아도** 됩니다)
3. **모드**를 **표 추출**(기본), **언어**를 **한국어**로 둡니다.
4. **[▶ 인식 실행]** 클릭. (최초 1회는 모델 로딩으로 시간이 걸립니다)
5. 오른쪽에 표가 **격자**로 표시되고, 결과가 **`결과\` 폴더에 자동 저장**됩니다.
   (표가 여러 개면 탭으로 구분)
6. 다른 위치·형식으로 저장하려면 **[💾 Excel]** / **[💾 CSV]**, 또는 **[📋 복사]** 후 엑셀에 붙여넣기.

### 결과 자동 저장

| 모드 | 저장 파일 |
|---|---|
| 표 추출·사용자관리 | `결과\원본이름_표.xlsx` (표마다 시트 1개) |
| 일반 텍스트 | `결과\원본이름_텍스트.txt` (UTF-8). PDF + 문장 정제면 `원본이름_텍스트.md` 도 함께 |
| 폴더 일괄 (표) | `결과\폴더이름_통합.xlsx` (통합 시트 + 파일별 시트) |
| 폴더 일괄 (일반 텍스트) | PDF 마다 `결과\원본이름_텍스트.txt` (+ `.md`) |

같은 이름의 파일이 있으면 덮어쓰지 않고 `_2`, `_3` 을 붙입니다. 저장 위치는 상태줄에 표시됩니다.

### 일반 텍스트 후처리 (두 번째 줄 체크박스)

- **문장 정제**: 끄면 쪽마다 `===== N 페이지 =====` 표시가 붙은 원문 그대로 나옵니다.
- **부속물 삭제**: 문장 정제가 켜져 있을 때만 선택할 수 있습니다. 지운 쪽은 상태줄에 쪽 번호로 알려 줍니다.
  표제지·헌사·저자 약력처럼 형태가 일정하지 않은 앞부속은 남을 수 있습니다.
  차례는 지우지 않고 결과 맨 앞에 목록으로 옮깁니다(책 구조 정비).

### 책 구조 정비 (PDF + 문장 정제)

스캔 PDF·텍스트 PDF 모두 이 순서로 처리합니다 (`engine\book_layout.py`).

1. **여백** — 쪽 위·아래 여백 띠에 따로 떨어진 줄 가운데 쪽번호뿐인 줄, 여러 쪽에 반복되는
   머리말·꼬리말('제1장 새로운 경영 패러다임 39')을 지웁니다. 같은 높이에 글줄이 있는 번호(차례의 쪽번호)와
   한 번만 나오는 쪽 맨 위 제목은 남깁니다. 줄 간격·들여쓰기로 단락 사이에 빈 줄을 넣습니다.
2. **차례 기준 정비** — 앞부분 차례 쪽에서 장·절 제목과 단계(부·장·`1.` 절·`1.1`)를 읽고, 본문에서
   같은 줄을 차례 순서대로 찾아 `#`(장)·`##`(절)… 제목으로 바꾸고 앞뒤에 빈 줄을 넣습니다.
   차례 쪽번호로 위치를 어림해 장 첫머리 목록 같은 엉뚱한 줄은 고르지 않습니다.
   장 표제지를 OCR 이 못 읽어 장 제목을 못 찾으면, 그 장의 첫 절 제목 앞에 장 제목을 넣습니다.
3. **정제** — 기존 문장 정제. 제목 줄은 줄 잇기에서 붙이지 않습니다.

- **MD**: 맨 앞에 `# 차례` 목록(장·절 들여쓰기) + 본문(장·절 MD 제목).
- **TXT**: MD 와 내용·줄바꿈이 같고 `#`·목록 기호만 뺍니다.
- 상태줄에 지운 여백 줄 수와 `차례 N항목 중 M개를 본문 제목으로 정비` 를 알려 줍니다.
  **차례를 찾지 못한 문서**(짧은 기사 등)는 장·절 정비 없이 정제만 하고 그렇다고 알립니다.

## 폴더 일괄 처리 (여러 이미지 → 하나의 표)

여러 장의 표 이미지를 한 폴더에 모아, 한 번에 **하나의 통합 데이터셋**으로 만듭니다.

**GUI에서:**
1. **[📁 폴더 일괄]** 클릭 → 이미지가 든 폴더 선택 (폴더를 미리보기 영역에 끌어다 놓아도 됨)
2. 확인하면 각 이미지를 순서대로 표 인식 (진행 상황이 상태바에 표시)
3. 완료되면 **[통합]** 탭에 모든 표가 `출처파일` 열과 함께 합쳐져 표시되고, `결과\` 에 자동 저장됩니다.

**드래그앤드롭 / 명령줄 (자동화):**
- `batch_run.bat` **위에 이미지 폴더를 끌어다 놓으면** 자동 실행
  → 이미지 폴더 안에 `폴더명_통합.csv` / `폴더명_통합.xlsx` 생성 (같은 이름이 있으면 `_2`, `_3` 을 붙임)
- 또는 명령줄 (최상위 폴더에서):
  ```
  engine\venv\Scripts\python.exe engine\batch_folder.py "C:\경로\이미지폴더" --lang korean
  ```
  옵션: `--recursive`(하위 폴더까지), `--out 접두어`, `--no-dedup-header`(반복 헤더 유지)

> **통합 규칙**: 각 행 앞에 `출처파일` 열이 붙고, 첫 이미지의 헤더를 대표로 삼아
> 이후 이미지의 동일한 헤더 행은 자동으로 생략합니다.
> (같은 양식의 표 여러 장을 이어붙일 때 최적입니다.)

> **팁 (정확도 높이기)**: 표 선이 뚜렷하고 해상도가 높을수록 정확합니다.
> 저해상도는 자동 확대되지만, 원본이 선명할수록 좋습니다.

## 폴더 일괄 처리 (여러 PDF → 파일마다 텍스트)

책·기사 PDF 여러 개를 한 번에 텍스트로 뽑습니다. PDF 마다 `결과\원본이름_텍스트.txt` 와
(문장 정제를 켜면) `.md` 가 따로 저장됩니다. 처리 순서는 위 「책 구조 정비」와 같습니다.

**GUI에서:** 모드를 **일반 텍스트**로 두고 **[📁 폴더 일괄]** → PDF 가 든 폴더 선택
(문장 정제·부속물 삭제 체크박스가 그대로 적용됩니다).

**드래그앤드롭 / 명령줄:** `batch_run.bat` 위에 **PDF만 든 폴더**를 끌어다 놓으면 자동으로 텍스트 모드가 됩니다.
```
engine\venv\Scripts\python.exe engine\batch_folder.py "C:\경로\PDF폴더" --text
```
옵션: `--out 폴더`(저장 위치, 기본 `결과\`), `--no-refine`(정제 끄기 — 쪽별 원문 TXT), `--drop-matter`(부속물 삭제),
`--recursive`. 스캔 PDF 는 쪽마다 OCR 하므로 오래 걸립니다(실측 약 2.5초/쪽).

## 폴더 구성 (엔드유저 2계층 구조)

```
MyOCR/
├── run.bat                 # GUI 프로그램 실행 (더블클릭)
├── batch_run.bat           # 폴더 일괄 추출 실행 (폴더 드래그앤드롭 / 더블클릭)
├── 결과/                   # 인식 결과 자동 저장 폴더 (xlsx, txt, md)
│
├── engine/                 # 내부 엔진 및 가상환경 격리
│   ├── ocr_app.py          # GUI 애플리케이션
│   ├── ocr_engine.py       # 텍스트 OCR 엔진 (RapidOCR 한글 v5)
│   ├── table_engine.py     # 표 구조 인식 엔진 (RapidTable + RapidOCR)
│   ├── uth_fixed_engine.py # 고정 레이아웃 전용 엔진
│   ├── korean_corrector.py # 한글 맞춤법/띄어쓰기 정제 모듈
│   ├── text_refiner.py     # 문장 정제·부속물 삭제 (일반 텍스트 모드)
│   ├── book_layout.py      # 책 구조 정비 (여백 제거 → 차례 기준 장·절 → MD/TXT)
│   ├── batch_folder.py     # 폴더 일괄 처리 CLI
│   ├── batch.py            # 일괄 처리 모듈 (헤더 병합)
│   ├── exporters.py        # 엑셀/CSV/TSV 저장 모듈
│   ├── install.bat         # 가상환경 구축 스크립트
│   ├── requirements.txt    # 패키지 의존성 명세
│   ├── tests/              # 회귀 테스트 스크립트
│   └── venv/               # 독립 가상환경
│
├── docs/                   # 사용자 가이드 및 인수인계 문서
│   └── README.md
│
└── samples/                # 테스트용 샘플 이미지
    ├── test_batch/
    └── test_table.png
```

## 문제 해결

- **`install.bat` 이 "venv 생성 실패"** → Python이 없거나 PATH에 없음.
  python.org 정식 버전(3.10~3.12) 설치(Microsoft Store 버전보다 권장) 후 재시도.
- **끌어다 놓기가 안 됨** → `engine\install.bat` 을 다시 실행하세요 (tkinterdnd2 설치). 버튼으로 여는 것은 그대로 됩니다.
- **표를 못 찾음 / 셀이 어긋남** → 표 선이 흐리거나 기울어진 스캔은 정확도가 떨어집니다.
  반듯하고 선명한 캡처를 쓰거나 표 부분만 잘라서 넣어 보세요.
- **첫 인식이 오래 걸림** → 정상입니다. 최초 1회 인식 모델을 로딩/다운로드하는 중입니다.
- **한글이 이상하게 인식됨** → 언어가 "한국어"인지 확인하세요.
- **테스트 실행** (최상위 폴더에서):
  ```
  engine\venv\Scripts\python.exe engine\tests\test_pipeline.py
  engine\venv\Scripts\python.exe engine\tests\test_text_refiner.py
  engine\venv\Scripts\python.exe engine\tests\test_book_layout.py
  python -m pytest engine\tests\test_korean_corrector.py -q
  ```
  마지막 줄(한글 교정기 회귀 테스트)은 pytest 가 필요해 pytest 가 깔린 Python 으로 돌립니다.
