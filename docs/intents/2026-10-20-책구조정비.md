# Intent: 책 OCR 구조 정비 (여백·머리글 제거 → 목차 기준 단락 정비 → 정제)

> 기본 증거등급: `E1`(사용자 답변·코드 직접 확인). 추정 항목은 본문에 "추정"으로 표시한다.

## 1. 배경 및 문제
- 현재 문제 (사용자 답변 2026-10-20):
  - 반복 머리말·꼬리말·쪽번호가 본문에 남는다.
  - 단락·줄바꿈이 엉망이다(제목이 본문에 붙거나 단락이 잘못 이어지거나 끊김).
  - 목차의 장·절 제목이 결과에서 제목으로 드러나지 않는다.
- 원인으로 보이는 현재 구조 (코드 확인):
  - `engine/ocr_engine.py:152` `_run()` 이 RapidOCR 결과에서 글자·점수만 남기고 **위치 상자(좌표)를 버린다** → 여백·본문 영역을 구분할 근거가 없다.
  - `engine/text_refiner.py:23` `refine_pages()` 의 쪽번호·머리글 제거는 **글자 패턴·쪽 간 반복**만으로 판정한다.
  - 목차는 `부속물 삭제` 때 **지우는 대상**으로만 쓰이고(`noise_rules._is_toc_page`, `text_refiner._drop_toc`), 장·절 구조 복원에는 쓰이지 않는다.
  - 텍스트 PDF는 `ocr_pdf()` 에서 `page.get_text("text")` 로 줄 글자만 받아 위치·글자 크기를 쓰지 않는다.
- 영향받는 업무/사용자: MyOCR '일반 텍스트' 모드로 책(스캔 PDF·텍스트 PDF)을 텍스트화하는 사용자.

## 2. 목표
- 달성하려는 결과: 처리 순서를 아래 3단계로 고정한다.
  1. **여백·본문 인식** — 쪽마다 본문 영역과 위·아래 여백을 위치로 구분해, 여백에 있는 쪽번호·반복 머리말·꼬리말을 제거한다.
  2. **목차 기준 구조 정비** — 목차에서 장·절 제목과 계층을 읽고, 본문에서 그 제목 줄을 찾아 MD 제목으로 표시하며, 제목 앞뒤를 빈 줄로 확실히 끊고 단락·줄바꿈을 그 경계 기준으로 정리한다.
  3. **정제** — 그 뒤에 기존 문장 정제(잡음·끊긴 줄 잇기·교정 등)를 돌린다.
- 출력:
  - **MD**: 맨 앞에 목차를 MD 목록(쪽번호 제외, 장·절 계층 들여쓰기)으로 두고, 본문의 장·절 제목은 `#`·`##` 제목, 제목 앞뒤 빈 줄.
  - **TXT**: MD와 내용·줄바꿈이 같고 `#`·목록 기호만 뺀다(제목 앞뒤 빈 줄 유지).
- 성공 기준 (실물 샘플로 확인 — 수치는 「8. 미해결 질문」에서 합의):
  - 표본 쪽에서 쪽번호·반복 머리말·꼬리말 잔존 0건.
  - 목차 항목 중 본문에서 MD 제목으로 찾은 비율 ≥ 90%.
  - 머리말·꼬리말로 오인해 지운 본문 줄 0건(정제 전후 대조).
  - 모든 장·절 제목 앞뒤에 빈 줄.
  - 목차 없는 책은 지금과 같은 결과 + 상태줄 알림.

## 3. 범위
### 포함
- 입력: **스캔 PDF**(OCR), **텍스트 레이어 있는 PDF**(내장 텍스트).
- OCR·PDF 텍스트의 위치 정보(상자 좌표, 텍스트 PDF는 글자 크기 포함)를 정제 단계까지 전달.
- 위치 기반 여백·본문 구분과 머리말·꼬리말·쪽번호 제거.
- 목차 쪽 인식 → 장·절 제목·계층 추출 → 본문 제목 매칭 → MD 제목·빈 줄 정비.
- 결과를 `.md` 와 `.txt` 두 형식으로 저장.
- `부속물 삭제`를 켜도 목차는 결과 맨 앞 MD 목록으로 보존.
### 제외
- 이미지 폴더(쪽마다 캡처한 이미지 묶음) 입력 — 사용자가 대상에서 뺐다.
- 표 추출·사용자관리(고정양식) 모드.
- 목차 없는 책의 제목 추정(글자 크기 등) — 지금 방식으로 처리하고 알림만.
- 장별 파일 분할.

## 5. 제약 조건
- 완전 오프라인(로컬 OCR, RapidOCR 한글 v5). LLM 쓰지 않음.
- `engine/noise_rules.py` 는 01_OCR 원본을 바이트 그대로 복사한 파일이다(`text_refiner.py` 머리 주석). 여기를 고치려면 01 원본을 고치고 다시 복사해야 한다 → 새 기능은 MyOCR 쪽 새 코드로 두는 것을 우선 검토.
- `korean_corrector.py` 는 세 프로그램 공통본(md5 관리) — 이번 작업에서 수정하지 않는다.
- 기존 회귀 테스트(`engine/tests`)가 계속 통과해야 한다.
- 목차 없는 책·위치 정보가 없는 경우의 결과는 지금과 같아야 한다(회귀 없음).

## 6. 주요 프로세스
1. PDF 쪽마다 줄 글자 + 위치 상자를 얻는다(스캔: RapidOCR 상자, 텍스트 PDF: PyMuPDF 줄 위치·글자 크기).
2. 책 전체 쪽의 줄 위치 분포로 본문 영역(위·아래 여백 경계)을 정하고, 여백 줄 중 쪽번호·반복 머리말·꼬리말을 지운다.
3. 앞부분에서 목차 쪽을 찾아 장·절 제목과 계층(들여쓰기·번호 체계)을 추출한다.
4. 본문에서 목차 제목과 일치하는 줄을 찾아 MD 제목(`#` 장, `##` 절)으로 바꾸고 앞뒤에 빈 줄을 넣는다. 제목 경계는 줄 잇기 대상에서 뺀다.
5. 기존 정제(잡음 제거·끊긴 줄 잇기·쪽 경계 문장 잇기·교정)를 실행한다.
6. 맨 앞에 목차 MD 목록을 붙여 `.md` 저장, `#`·목록 기호를 뺀 `.txt` 저장. 목차를 못 찾았으면 상태줄에 알린다.

## 7. 예외 및 리스크
| 상황 | 처리 방향 |
|---|---|
| 목차 없음·인식 실패 | 2단계(목차 정비)를 건너뛰고 지금 방식으로 정제, 상태줄 알림 |
| 목차 제목과 본문 제목 표기가 다름(OCR 오인식·줄바꿈·띄어쓰기) | 유사도 매칭. 못 찾은 항목은 보고에 남김(지어내 넣지 않음) |
| 짧은 문서(DBR 기사 등)는 목차가 없을 가능성이 큼 | 목차 없는 경로로 처리(추정 — 샘플로 확인 필요) |
| 여백에 본문 줄이 걸침(첫 줄이 위로 붙은 쪽, 그림 캡션) | 쪽 간 반복·패턴과 함께 판정해 본문 삭제 방지. 지운 줄 수 보고 |
| 펼침면 스캔·좌우 쪽 머리글이 다름 | 홀짝 쪽을 나눠 판정(추정 — 샘플로 확인 필요) |
| 목차 쪽번호와 실제 PDF 쪽 차이 | 쪽번호는 매칭 보조로만 쓰고 의존하지 않음 |
| 정제 끔 | 지금처럼 원문 + `===== N 페이지 =====` (변경 없음) |
